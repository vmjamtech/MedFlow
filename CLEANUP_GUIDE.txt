TROUBLESHOOTING
================================================================================

If files won't delete:
  - Close VS Code editor
  - Stop npm dev server (Ctrl+C)
  - Close any other apps using the files
  - Try delete again

If npm install fails after deletion:
  - Delete package-lock.json
  - Run: npm install
  - Wait for completion

If app won't start:
  - You deleted the wrong file!
  - Restore from git: git checkout [filename]
  - Refer to "KEEP" section above

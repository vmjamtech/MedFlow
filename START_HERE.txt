================================================================================
                   TROUBLESHOOTING
================================================================================

BLANK PAGE ON LOAD
  → Check browser console for errors
  → Verify app.html imports src/main.ts
  → Ensure vite.config.ts is configured

DATA NOT PERSISTING
  → Check localStorage limits (5-10MB typically)
  → On Android: Verify Capacitor SQLite plugin installed
  → Try: localStorage.clear() then refresh

STYLING BROKEN
  → Tailwind CSS not compiling?
  → Run: npm install
  → Check: tailwind.config.js and postcss.config.js exist

BUTTONS NOT WORKING
  → Check browser console for errors
  → Verify onclick handlers reference window functions
  → Ensure src/main.ts loaded successfully

TYPE ERRORS IN IDE
  → Run: npm run type-check
  → Check: tsconfig.json exists
  → Try: npm install
